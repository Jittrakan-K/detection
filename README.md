# นับชิ้นงานด้วยกล้อง (Detection)

เว็บแอปนับชิ้นงานที่ไหลผ่านกล้อง เช่น น็อตตัวผู้ M6 ใช้ได้ทั้งบนคอมพิวเตอร์และมือถือ เป็นไฟล์ HTML ไฟล์เดียว ประมวลผลในเครื่องทั้งหมด ไม่ส่งภาพออกไปที่ไหน

**เปิดใช้งาน:** https://jittrakan-k.github.io/detection/ (หลังเปิด GitHub Pages)

## หลักการทำงาน

1. แยกชิ้นงานออกจากพื้นหลัง ด้วยการเรียนรู้พื้นหลังอัตโนมัติ หรือใช้ระดับความสว่างตัดสิน (ชิ้นงานเข้มบนพื้นสว่าง / สว่างบนพื้นเข้ม)
2. รวมพิกเซลที่ติดกันเป็นก้อน และกรองด้วยขนาดเล็กสุดและใหญ่สุด
3. ติดตามแต่ละก้อนข้ามเฟรม นับ +1 เมื่อจุดกลางของก้อนข้ามเส้นนับตามทิศทางที่ตั้งไว้ ชิ้นเดียวไม่ถูกนับซ้ำ
4. ชิ้นที่ไหลติดกัน: เปิด "แยกนับตามขนาดก้อน" แล้วกด "เรียนรู้ขนาด 1 ชิ้น" ก้อนที่ใหญ่ราว 2 เท่าจะนับเป็น 2 ชิ้น

## ฟังก์ชัน

- แหล่งภาพ: ภาพจำลองสายพาน, กล้องสด (เลือกกล้องได้), ไฟล์วิดีโอ หรือถ่ายวิดีโอด้วยมือถือ
- กำหนดพื้นที่ตรวจจับด้วยการลากบนภาพ ปรับทิศทางการไหลและตำแหน่งเส้นนับ
- ตั้งเป้าหมาย (เช่น 1000 ชิ้น) มีเสียงเตือนเมื่อครบ และเลือกหยุดนับอัตโนมัติได้
- ปุ่ม ±1 แก้ยอดด้วยมือ คีย์ลัด: `Space` เริ่ม/หยุด, `+` / `-` ปรับยอด
- อัตราชิ้นต่อนาที เวลานับ จำนวนคงเหลือ
- ประวัติรอบการนับ คัดลอกไปวางใน Excel ได้
- ยอดนับและการตั้งค่าเก็บไว้ในเบราว์เซอร์ ปิดหน้าแล้วเปิดใหม่ยอดยังอยู่
- ระหว่างนับ หน้าจอไม่ดับเอง (ถ้าเบราว์เซอร์รองรับ)

## ตั้งค่าให้นับแม่น

1. ยึดกล้องให้นิ่ง มองลงตั้งฉากกับทางไหล
2. ใช้พื้นหลังสีตัดกับชิ้นงาน และให้แสงสม่ำเสมอ ไม่มีเงาแข็ง
3. กำหนดพื้นที่ให้ครอบเฉพาะช่วงรางที่ชิ้นงานวิ่ง
4. เปิด "แสดงพื้นที่ที่ตรวจจับได้" แล้วปรับความไวจนชิ้นงานเป็นก้อนเต็มตัว และพื้นว่างไม่มีจุดรบกวน
5. ชิ้นงานควรเลื่อนไม่เกินประมาณ 1/5 ของภาพต่อเฟรม
6. ก่อนใช้งานจริง ปล่อยชิ้นงานที่นับมือไว้แล้ว 100–200 ชิ้น เทียบผลแล้วจูนค่าจนตรง
